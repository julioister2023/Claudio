# Assets

Drop production assets here. The home page (`../index.html`) references them by path.

## Required

| File | Used in | Notes |
|------|---------|-------|
| `logo.png` | Nav (header) + Footer | Official Colegio Americano de Guayaquil logo. Transparent PNG recommended. Shown ~46px tall in the nav; the footer places it on a white chip for contrast against the dark background. |
